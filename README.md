# AIR-pixel Liquid Glass

A configurable Liquid Glass theme for DeepSeek Harness.

Features include translucent interface surfaces, custom wallpaper, desktop transparency, window blur, custom cursors, click ripples, and per-side conversation contrast controls.

## Install

Install `air-pixel-liquid-glass` from the DeepSeek Harness plugin market, or load this plugin directory with the local plugin loader.

## Configuration

Open the plugin settings in DeepSeek Harness to adjust the available appearance options. The theme supports light and dark interfaces.

## Development

See [DEVELOPMENT.md](DEVELOPMENT.md) for local validation and packaging notes. The plugin manifest and patch are `package.json` and `cordis.patch.yml`.
